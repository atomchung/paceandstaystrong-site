隱私權政策

最後更新：2026 年 9 月 11 日 · 由一位在台灣的獨立開發者營運。

本頁是中文譯本，僅供閱讀方便。正式版本是英文版隱私權政策；兩份文字若有任何出入，以英文版為準。

這份政策說明 Long Run Hybrid Coach 會處理哪些資料、為什麼需要、資料流向哪裡，以及要怎麼撤銷授權或刪除產品端保存的資料。

1. 處理哪些資料，以及用途

資料用途
已完成的活動拿計畫去對你實際完成了什麼，並維持當前方向。
可取得的健康摘要在資料存在且不過期時，作為教練判斷的依據。缺少或過期的欄位維持「不知道」。
日曆上已排定的課表讀取目前的日曆、避免重複佔用同一筆行程，並且只發佈你同意過的課表。
目標、限制與偏好讓計畫真的塞得進你的行程，也符合你講出來的方向。
你自己回報的訓練與身體紀錄保存裝置記不到的東西：你回報的重訓組數、你描述的訓練、你說出來的體重或體脂，以及你上傳的訓練歷史檔案。每一筆都存成「運動員自述」，絕不會被悄悄升級成供應商的實測值。有支援的紀錄可以透過教練更正或撤回。
你說自己感覺如何，以及你講出來的恢復數字用你自己的話作為教練判斷的依據——包含你從裝置上讀到的心率、HRV 或睡眠數值。主觀陳述會以陳述本身保存，不會被換算成分數。單次請求範圍內的恢復讀數只用於那一輪對話，不會被留成供應商原始資料。
OAuth 授權在你授予的權限範圍內存取你的 Intervals.icu 帳號。絕不收集你的 Intervals.icu 密碼。

2. 儲存與授權

使用託管 gateway 時，它會儲存以擁有者為範圍的產品狀態，包含 PlanState 各版本、決策與回執、運動員自述的紀錄，以及維持單一當前計畫所需的交付紀錄。供應商身分與一組帶金鑰的 token 指紋分開儲存，讓不同請求能對應到同一位擁有者。

Intervals.icu OAuth 的原始 access token 只用於發出已授權的請求，不會寫進擁有者狀態儲存區，也不會寫進應用程式日誌。OAuth client secret 留在伺服器端，不會暴露給當下使用的 AI 介面。

3. AI 處理

Long Run Hybrid Coach 可以透過 ChatGPT、Claude 或其他支援的 AI 介面使用。當下使用的那個介面，會依照該 AI 供應商自己適用的條款與隱私權政策，處理這次教練任務所需的訓練脈絡。用到哪個介面，取決於你選擇從哪個入口進來。

Gateway 不會拿訓練資料去訓練自有模型。目前的程式庫不會另外呼叫大型語言模型 API，也不需要你提供 AI API key。如果你不希望訓練或健康資訊被你所選介面背後的 AI 供應商處理，請不要使用那個介面。

4. 連接的平台

Long Run Hybrid Coach 會在你授予的權限範圍內，讀取與寫入 Intervals.icu。Intervals.icu 依照它自己的條款與隱私權政策處理那些資料。本產品不會販售訓練資料、不會用於廣告，也不會寫入已完成的活動或健康紀錄。

5. 保存、更正與刪除

以擁有者為範圍的訓練狀態會保存到你刪除為止，好讓當前的決策可以被對帳與稽核。沒有到期時間，也沒有閒置清理機制。

在對話裡：用你原本就在用的那條連線，請教練給你一份資料副本。刪除全部資料不在那裡進行，也沒有任何工具做得到——你問教練，它會回覆下面那條支援頁的說明。

用 email：寫信到 tingcctwai@gmail.com。刪除資料只有這一條路，匯出也可以這樣提出。它不必仰賴你的 AI 用戶端放行：有些 AI 用戶端會在它自己的核准步驟就擋掉工具呼叫，請求根本沒送到本服務，這種時候對話既完成不了你的請求，也說不出原因——所以無法回復的那個操作不放在那裡。你提供自己的 Intervals.icu athlete id，以及（在你進得去那個頁面時）一張 Intervals.icu Settings 頁的截圖，接著由維運者執行匯出或刪除：副本只寄給提出該次請求的那個信箱，刪除則針對你確認過的那份範圍執行。不會有人跟你要密碼、API key 或授權 token。步驟寫在支援頁。

採用「最新覆蓋」鍵值的運動員自述紀錄，回報新值即可更正；有支援的運動員自述紀錄，在正確結果是移除而非取代時也可以撤回。這不會改寫只增不改的 PlanState／決策歷史：計畫的每次修訂仍然可稽核，而不是就地編輯。

刪除會移除計畫狀態、它的版本歷史、運動員自述的紀錄、存放在旁邊的快照，以及用來對應到你帳號的身分映射。它不會移除已經寫進你 Intervals.icu 日曆的課表，也不會撤銷你在 Intervals.icu 的授權。本產品不建立例行備份；若有部署啟用了主機層級的磁碟區快照，該部署必須自行說明其保存行為。

不承諾任何備份保存期限，因為從來沒有量測過——這與支援頁上已經寫明的說法一致。

要立刻停止之後的存取，請在 Intervals.icu 撤銷 Long Run Hybrid Coach。撤銷會擋掉之後所有經授權的讀取與寫入，但它本身不會刪除產品端保存的狀態或身分映射；如果你要的是刪除，請另外提出刪除申請，先後順序都可以——email 那條路不需要可用的連線。已經在你 Intervals.icu 日曆上、由本產品建立的課表，請在該處管理。

6. 安全性

授權採用 OAuth。原始 access token 不會被保存或寫入日誌；帳號查找使用帶金鑰的 HMAC-SHA256 指紋。擁有者狀態以擁有者識別碼區隔，憑證不會提交進版本控制，私人訓練紀錄也不屬於這個公開的網站程式庫。

7. 你的選擇與權利

你可以在對話裡存取、匯出、更正或撤回有支援的運動員自述紀錄，也可以用 email 提出刪除與你擁有者帳號相關的託管資料（見第 5 節）。你也可以隨時透過 Intervals.icu 撤銷它的存取權。PlanState 歷史本身不會就地編輯；刪除擁有者資料時，它會一併被移除。

8. 兒童

Long Run Hybrid Coach 不適用於未滿 16 歲者，也不以兒童為對象。

9. 非醫療建議

Long Run Hybrid Coach 是訓練規劃工具。它不診斷、不治療、不監測任何醫療狀況，也不能取代合格的醫療照護或真人教練。

10. 聯絡

更正與撤回不需要聯絡任何人——透過你已驗證的連線回報正確的值即可。匯出同樣可以這樣做，也可以用 email 提出；刪除資料一律是 email 申請（見第 5 節）。其他事情請走支援頁：寫信到 tingcctwai@gmail.com，這個信箱是私下的，任何牽涉到你健康資料或帳號的事情都該走這裡。公開的程式庫 issue tracker 仍然開放給 bug 與功能建議；不要在公開 issue 裡放健康資料、憑證、OAuth token 或其他私人資訊。你的資料匯出檔裡印出的那組不透明帳號代碼，可以安全地在公開場合引用，而且足夠讓維運者找到你的帳號。

11. 變更

這份政策若有實質變更，上方的更新日期會改變，新版本會發佈在同一個網址。
