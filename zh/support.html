連接遇到問題，先從下方排查開始。要匯出、更正或刪除資料，可以直接請教練處理；如果那條路走不通，改用 email 提出匯出或刪除。

連接與第一次使用

  • 找不到新增連接器？先查看支援的 AI 方案。Claude 免費方案限一個自訂連接器；團隊帳號也可能需要管理員開放。
  • 已新增，但教練讀不到資料？確認連接器顯示已連接，並在目前對話裡啟用它。若提示缺少權限，重新連接並檢查 Intervals.icu 的四項授權。
  • 連接成功，卻沒有訓練紀錄？查看 Intervals.icu 本身是否已有活動。沒有也能先口述訓練與目標；新帳號的開始方式。
  • 課表已傳送，手錶卻看不到？先在 Intervals.icu 日曆確認課表，再檢查裝置同步設定。日曆收到不代表手錶已收到。

回到完整設定步驟 · 聯絡開發者

來信請說明使用的 AI、卡在哪一步及錯誤訊息，先移除私人資料。請勿傳送密碼、API key 或授權 token。

1. 在對話裡管理你的資料

  • 拿一份你的資料副本。問教練它握有你的哪些東西。壓縮檔會在對話裡給你，並且會說明它刻意沒放進去的是什麼。
  • 刪除你的帳號。請教練刪掉。你會先看到一份預覽，寫清楚什麼會被移除、什麼是刪除碰不到的；在你確認那份預覽之前，不會移除任何東西。
  • 更正你回報過的東西。回報正確的值就好。有些紀錄只算最新的那一筆——某一天的身體量測、或某個動作某一天練了什麼——新的值會取代目前那筆，教練也會告訴你被擠掉的是哪一筆。計畫本身的版本歷史是另一回事：它只會往後加，不會就地改寫，所以更正一筆紀錄不會偷偷改掉你上週看到的計畫。
  • 撤回你回報過的東西。當正確的結果是移除而不是取代時，請教練撤回相對應的那筆運動員自述紀錄。
  • 停掉全部的存取。在 Intervals.icu 撤銷 Long Run Hybrid Coach。這會終止之後的讀取與寫入；它本身不會刪掉已經保存的東西。連資料也想刪的話，先刪再撤銷——你的 Intervals.icu 登入就是這裡辨識你的依據，撤銷之後你可能得再短暫授權一次才能把刪除做完（見第 6 節）。

你的連線本身就是身分驗證，所以這些事都不需要另外開支援請求。如果你的 AI 用戶端在請求送到本服務之前就把它擋掉，改用 email 提出——那條路不靠工具呼叫成功。

2. 找到真人，以及用 email 要你的資料

Email：tingcctwai@gmail.com。它直接寄到開發者手上，而且是私下的，所以任何牽涉到你健康資料、訓練或帳號的事情都該走這裡。公開的 issue tracker 是給其他人也看得到才有價值的 bug 與功能建議用的——在那邊發文之前，先讀下一段。

如果教練匯不出、也刪不掉你的資料，寫信到這裡，會有人幫你做完。有些 AI 用戶端會在它自己的核准步驟就擋掉工具呼叫，請求根本沒送到本服務；這種時候對話既完成不了請求，也說不出原因。這條路不靠工具呼叫：

  1. 寫信到 tingcctwai@gmail.com，說明你要的是資料副本還是刪除，並附上你的 Intervals.icu athlete id——就是你自己 Intervals.icu 網址裡的那組數字。
  2. 你會收到回信，請你附一張 Intervals.icu Settings 頁的截圖，上面看得到那組 athlete id，以及已授權應用程式裡的 Long Run Hybrid Coach。一張截圖就好，不用來回。進不去那個頁面的話說一聲，athlete id 就夠了。
  3. 不會有人跟你要密碼、API key 或授權 token。兩條路都用不到它們，寄來也不會被讀。
  4. 要副本：檔案只寄給提出該次請求的那個信箱。要刪除：你會先收到完整範圍，在你確認那份範圍之前不會移除任何東西，事後的回信會附上刪除回執。

這是一個只有一位維護者的個人專案。沒有保證的回覆時間，這裡也不做這種承諾。上面那些你能自己做的事，都比等人回覆快。

如果你認為你找到了安全性或隱私漏洞，請不要公開描述它。改用 email 告訴我。

3. 哪些東西絕對不能放進公開 issue

Issue tracker 是公開且永久的。它必須在你不揭露任何東西的前提下仍然可用，所以請不要張貼——你也永遠不會被要求提供：

  • 健康、訓練或計畫內容，包含它們的螢幕截圖；
  • Intervals.icu 的 athlete id、owner id、access token 或 token 指紋；
  • 任何形式的密碼、OAuth 憑證或 API key。

要辨識你的帳號，足夠的是你自己資料匯出檔裡印出的那組不透明帳號代碼。它可以安全地公開引用，無法被還原成帳號 id，而且維運者靠它就能找到你。

4. 支援做得到什麼、做不到什麼

  • 在對話裡做的匯出與刪除立即生效，因為是你自己執行的。走 email 就是回信多久、它就多久——回覆時間見上面那段。
  • 刪除會在同一次操作裡涵蓋整個帳號，以及存放在旁邊的每一份快照。
  • 刪除碰不到已經寫進你 Intervals.icu 日曆的課表，也不會撤銷你在 Intervals.icu 的授權。這兩件事都由你自己移除。
  • 你自己回報的紀錄可以透過教練更正或撤回。計畫本身的版本與決策歷史不一樣：它只會往後加，不會被人工改寫。
  • 不承諾任何備份保存期限，因為從來沒有量測過。本產品不建立例行備份。
  • 如果你走的是 email 那條路，那封信件往來——你的信箱、athlete id、你附的東西，以及寄回去的那份檔案——是在信箱裡，不在服務裡，所以刪除你的資料碰不到它。說一聲就會手動刪掉。

5. 如果刪除被拒絕

有三個已知原因，三個你都可以自己排除。如果你看到的不是這三個——或者你的 AI 用戶端在請求送到本服務之前就擋掉了它——改用 email 提出。

  • 有一次交付還沒結束。Intervals.icu 可能握著一筆產品還沒對帳的課表。重跑同一次交付，或去看你的日曆並清掉那次嘗試，然後再刪除。
  • 帳號在你看過預覽之後變了。你在預覽和確認之間回報了一組重訓，或是有一堂課完成對帳了。重新預覽一次。
  • 你的資料正在被搬移。維運者正在遷移它。等遷移完成之後再重新預覽。

6. 如果你已經連不上了

如果你撤銷了 Intervals.icu 授權，或失去了那個帳號，對話就認不出你了——它用的就是你的 Intervals.icu 登入。就算只是短暫地重新授權一次，那條路也會恢復。做不到的話，改用 email 提出：那邊靠你的 athlete id 就找得到帳號，還進得去 Settings 頁的話就附張截圖。也請知道這代表什麼：離開對話之後，本服務沒有任何可以自動評估的所有權證明，核對的是一個人在讀你寄來的東西，防止別人冒用你並不是本產品聲稱做得到的事。

7. 這不是醫療支援

Long Run Hybrid Coach 是訓練規劃工具。它不診斷、不治療、不監測任何東西，這一頁也不是醫療管道。疼痛、生病或不尋常的症狀，要找合格的醫療照護，不是找教練，也不是開 issue。
