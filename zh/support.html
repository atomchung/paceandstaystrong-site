支援

最後更新：2026 年 8 月 20 日 · 這是個人 GitHub 專案，不是公司，由一位在台灣的獨立開發者維護。

多數人會寫信來問的事，你其實可以在原本那段和教練的對話裡自己做完——而且比任何人幫你做都快。先從那邊開始；這一頁其餘部分處理的是剩下的情況。

1. 這幾件事你現在就能自己做

  • 拿一份你的資料副本。問教練它握有你的哪些東西。壓縮檔會在對話裡給你，並且會說明它刻意沒放進去的是什麼。
  • 刪除你的帳號。請教練刪掉。你會先看到一份預覽，寫清楚什麼會被移除、什麼是刪除碰不到的；在你確認那份預覽之前，不會移除任何東西。
  • 更正你回報過的東西。回報正確的值就好。採用「最新覆蓋」鍵值的運動員自述紀錄——例如某一天的身體量測、或某個動作某一天的重訓執行——會取代目前的那筆紀錄，並告訴你被擠掉的是什麼。這和只增不改的 PlanState 版本歷史是兩回事，後者永遠不會就地編輯。
  • 撤回你回報過的東西。當正確的結果是移除而不是取代時，請教練撤回相對應的那筆運動員自述紀錄。
  • 停掉全部的存取。在 Intervals.icu 撤銷 Long Run Hybrid Coach。這會終止之後的讀取與寫入；它本身不會刪掉已經保存的東西，如果你要的是刪除，請另外執行刪除。

你的連線本身就是身分驗證，所以這些事不需要另外開支援請求，也不需要證明你是誰。

2. 找到真人

Email：tingcctwai@gmail.com。它直接寄到開發者手上，而且是私下的，所以任何牽涉到你健康資料、訓練或帳號的事情都該走這裡。公開的 issue tracker 是給其他人也看得到才有價值的 bug 與功能建議用的——在那邊發文之前，先讀下一段。

這是一個只有一位維護者的個人專案。沒有保證的回覆時間，這裡也不做這種承諾。上面那些你能自己做的事，都比等人回覆快。

如果你認為你找到了安全性或隱私漏洞，請不要公開描述它。改用 email 告訴我。

3. 哪些東西絕對不能放進公開 issue

Issue tracker 是公開且永久的。它必須在你不揭露任何東西的前提下仍然可用，所以請不要張貼——你也永遠不會被要求提供：

  • 健康、訓練或計畫內容，包含它們的螢幕截圖；
  • Intervals.icu 的 athlete id、owner id、access token 或 token 指紋；
  • 任何形式的密碼、OAuth 憑證或 API key。

要辨識你的帳號，足夠的是你自己資料匯出檔裡印出的那組不透明帳號代碼。它可以安全地公開引用，無法被還原成帳號 id，而且維運者靠它就能找到你。

4. 支援做得到什麼、做不到什麼

  • 匯出與刪除立即生效，因為是你自己執行的。
  • 刪除會在同一次操作裡涵蓋整個帳號，以及存放在旁邊的每一份快照。
  • 刪除碰不到已經寫進你 Intervals.icu 日曆的課表，也不會撤銷你在 Intervals.icu 的授權。這兩件事都由你自己移除。
  • 運動員自述的「最新覆蓋」紀錄可以透過教練更正或撤回。只增不改的 PlanState／決策歷史不一樣：它不會被人工改寫。
  • 不承諾任何備份保存期限，因為從來沒有量測過。本產品不建立例行備份。

5. 如果刪除被拒絕

有三個已知原因，三個你都可以自己排除：

  • 有一次交付還沒結束。Intervals.icu 可能握著一筆產品還沒對帳的課表。重跑同一次交付，或去看你的日曆並清掉那次嘗試，然後再刪除。
  • 帳號在你看過預覽之後變了。你在預覽和確認之間回報了一組重訓，或是有一堂課完成對帳了。重新預覽一次。
  • 你的資料正在被搬移。維運者正在遷移它。等遷移完成之後再重新預覽。

6. 如果你已經連不上了

如果你撤銷了 Intervals.icu 授權，或失去了那個帳號，身分驗證也跟著沒了。本產品沒有任何可以評估的所有權證明——它持有的每一個識別碼，不是單向雜湊就是任何人都能宣稱的值——所以不會僅憑一句聲稱就刪除某個帳號。就算只是短暫地重新在 Intervals.icu 授權一次，自助路徑就會恢復，事情也能被正確處理。

7. 這不是醫療支援

Long Run Hybrid Coach 是訓練規劃工具。它不診斷、不治療、不監測任何東西，這一頁也不是醫療管道。疼痛、生病或不尋常的症狀，要找合格的醫療照護，不是找教練，也不是開 issue。
