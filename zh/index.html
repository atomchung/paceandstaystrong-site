四步驟完成連接

你需要兩樣東西：一個免費的 Intervals.icu 帳號，和 Claude 或 ChatGPT。教練會讀你帳號裡原本就有的訓練紀錄。還沒有帳號？第三步會帶你到 Intervals.icu 的登入頁，用 Google 帳號 30 秒內就能開好。

連接網址（Remote MCP URL） https://mcp.paceandstaystrong.com/mcp
  1. 開啟你 AI 的連接器設定。

    找新增連接器的選項。

    claude.ai 或 Claude Desktop：Settings → Connectors → Add custom connector。

    ChatGPT：完整的讀寫權限目前只在 Business、Enterprise、Edu 的網頁版 workspace 開放 beta，要透過 Apps／developer mode 啟用。其他人請先等這個連接在 ChatGPT 目錄上架。

  2. 貼上連接網址。

    把上面的網址貼進 remote MCP server 的 URL 欄位，然後繼續。MCP 是讓 AI 連上外部服務的標準介面——你只需要把網址貼進去。

    沒有別的欄位要填，也沒有金鑰要貼。這個網址就在這個專案自己的網域上——跟你現在看的這一頁同一個。

  3. 授權 Intervals.icu。

    Intervals.icu 跳出同意頁的時候先登入，四個權限都勾起來，再按核准。每個權限管一種存取。少勾哪一個，需要它的功能就會用很難查出原因的方式壞掉——要用完整的教練流程，四個都勾。

    四個裡面有一個是「寫入」你的 athlete settings，教練確實會寫，但範圍很窄：它從那一格讀你的門檻配速，唯一會寫進去的是你還沒有的門檻配速，而且發生在你已經確認過的課表交付當下。你已經設好的門檻配速絕不會被覆寫。

    看這個授權包含什麼範圍、要怎麼撤銷。

  4. 回到你的 AI，開始對話。

    確認這個連接在對話裡是打開的，然後請教練讀你最近的訓練。

第一句可以這樣講：「讀我最近的訓練，幫我訂出未來 28 天的跑步＋重訓方向。」

你的 Intervals.icu 帳號是新的還是空的？

教練會自動讀取 Intervals.icu 裡已經有的資料。如果帳號是新的，請它讀訓練之前，有兩種方法可以先把歷史資料補進去：

  • 連接你原本就在用的裝置或 app。在 Intervals.icu 自己的 Settings 裡，連上 Garmin 或你既有的手錶、訓練 app 帳號。過去的活動會自動補上——資料到了之後，再回來請教練重新讀一次你的訓練。
  • 直接把匯出檔交給教練。在對話裡把 CSV、Apple Health 匯出檔或 .fit 檔直接交給教練，請它匯入你的歷史紀錄。（檔案是給教練看的，不會加進 Intervals.icu。）

跑步和重訓，共用同一份當前計畫。

生活會變，訓練也該跟著變。少跑掉的那一趟、真的練完的那組重訓、不完整的恢復數據——這些都該影響接下來怎麼練。Long Run Hybrid Coach 會拿計畫去對你實際做了什麼，然後更新你唯一的當前方向。

重訓寫得很具體。

「背蹲舉 4×5、100 公斤」在你的計畫裡是一堂真的課，不是你留給自己的一行筆記。Intervals.icu 收到的是課表名稱；動作、組數、次數、重量留在對話裡，你隨時可以請它讀回來給你看。

連接之前你可能想問

這是一個要安裝的 app 嗎？

不是。它跑在你和 Claude 或 ChatGPT 的對話裡——連接一次之後，你就是跟它講話而已。沒有東西要下載，這裡不用另外註冊帳號，也沒有儀表板要你一直回去看。你的計畫在教練那裡，課表會落到你的 Intervals.icu 日曆。

開始之前需要準備什麼？

一個 Intervals.icu 帳號，以及 Claude 或 ChatGPT。上面的四個步驟有要貼的網址。還沒有 Intervals.icu 帳號也沒關係，它是免費的——設定流程會帶你到它的登入頁，用 Google 帳號大約 30 秒就能開好。Claude 用免費方案就可以，不過免費帳號只能放一個自訂連接器。ChatGPT 目前需要 Business、Enterprise 或 Edu workspace；個人方案請等這個教練在 ChatGPT 目錄上架。

這個要錢嗎？

不用。教練是免費的，也沒有付費方案——這是一個人的專案，不是公司，這裡根本沒有地方讓你輸入付款方式。真的可能要花錢的只有你的 AI 訂閱：Claude 用免費方案就可以，ChatGPT 目前需要 Business、Enterprise 或 Edu workspace。Intervals.icu 本身也是免費的。免費也代表這一頁最下面那句話：不保證服務不中斷，也可能改變。

一定要用特定的手錶嗎？

不用。只要活動紀錄和健康數據最後有進到你的 Intervals.icu 帳號，教練就能用。

我可以自己架，不用託管版本嗎？

可以。自架跑的是完全一樣的產品，用你自己的 Intervals.icu OAuth 憑證和你自己的儲存空間——這條路是給想自己維運的開發者走的。多數人直接用設定步驟裡的託管網址就好。

為什麼 Intervals.icu 四個權限都要勾？

它們讓教練能讀你完成的活動、讀你的健康數據、讀寫你的訓練日曆，以及讀寫你的 athlete settings。第四個是真的寫入權限，但用得很窄：教練從那裡讀你的門檻配速，唯一會寫進去的是你還沒有的門檻配速，而且發生在你已經確認過的課表交付當下；已經設好的絕不覆寫。它之所以重要，是因為 Intervals.icu 這邊沒有門檻配速時，它照樣收下有配速的課表，但往手錶送的時候會把配速目標拿掉——你會收到距離正確、卻沒有任何目標的一堂課。每個權限管的是不同一種存取。少勾哪一個，需要它的功能就會用很難查出原因的方式壞掉——要用完整的教練流程，四個都勾。

教練會不會沒經過我同意就寫課表？

不會。每一堂課都會先完整攤給你看，你確認的就是你看到的那一份，確認之後才寫入。

「交付成功」是什麼意思？

交付成功代表 Intervals.icu 已存下這堂課、教練也讀回來核對過。不代表你的手錶已經拿到。

要怎麼撤銷授權或刪掉我的資料？

要停掉存取：到你的 Intervals.icu 設定裡移除這個應用程式，之後的讀寫就停了。Intervals.icu 的授權是給整個應用程式、不是給單一個 AI，所以移除它會一次斷掉你連過的每一個 AI——Claude、ChatGPT，全部。

連資料也想刪掉的話，先刪再撤銷：在對話裡跟教練說，它會在你確認之前先讓你看到要移除的到底是什麼。先刪再撤銷是比較單純的順序——你的 Intervals.icu 登入就是這裡辨識你的依據，撤銷之後你可能得再短暫授權一次，才能把刪除做完。

不管哪一種，已經寫進 Intervals.icu 日曆的課表都還是你的，要留要刪都可以。更多細節在支援頁。
