差別在哪

一般 AI 聊天做不到的三件事。

隨便找個 AI 要一份週課表，也會得到一份看起來合理的。差別從教練接上你自己的訓練那一刻開始。

1

看你真的練了什麼

跑完、練完的紀錄從你自己的 Intervals.icu 進來。教練照著那些安排，不是照你當下想得起來、願意打字的內容。

2

跑步＋重訓一起排

同一份計畫包含兩邊，強度跑和大重量會互相錯開。兩張分開的課表做不到這件事，只會輪流把你的腿用完。

3

練完再調

漏了一堂，或週四突然沒了？回到對話改這份計畫。它記得你已經完成的部分，不會重發一張全新的泛用課表。

第一次用

四個步驟，大約五分鐘。

你需要一個 Intervals.icu 帳號（全新、沒有任何紀錄也可以），第一次設定建議用電腦瀏覽器。

  1. 先用 Claude。

    Claude 免費方案可以加一個自訂連接器，這樣就夠了。開啟 Claude 連接器設定。

    我用 ChatGPT

    完整教練流程目前需要 Business、Enterprise 或 Edu 網頁版，而且工作區要開放自訂 MCP 讀寫。請依 ChatGPT 官方設定說明，透過 Apps／developer mode 新增自訂 app。只有讀取權限無法儲存計畫或傳送課表，個人方案請先用 Claude。

  2. 加入 Long Run Hybrid Coach。

    在 Claude：Customize → Connectors →「＋」→ Add custom connector。名稱填 Long Run Hybrid Coach，伺服器網址貼上這一串。

    連接網址 https://mcp.paceandstaystrong.com/mcp
    還要填別的嗎？

    不用。沒有 API key，也不需要填 OAuth 憑證，就只有這串網址。團隊帳號可能要管理員先開放自訂連接器，選項才會出現。

  3. 登入 Intervals.icu 並授權。

    按 Connect，用你自己的帳號登入，四項權限全部勾選後再同意。四項權限各自涵蓋什麼。漏勾的話重新連接補上即可。

  4. 回到對話，開始使用。

    在對話的連接器／工具選單啟用 Long Run Hybrid Coach（Claude 是輸入框旁的「＋」→ Connectors），然後送出這句：

    先讀我最近的訓練，再問我目標和每週能練的時間，幫我安排跑步與重訓。

怎麼知道有連上？教練應該會回報它讀到的訓練紀錄，或明確說帳號目前還沒有資料。如果只得到一般建議，請它確認有沒有用到連接器。

Intervals.icu 是新帳號、沒有資料，也能用嗎？

可以。先告訴教練你最近怎麼練、每週有多少時間和想達成什麼，不必先補齊歷史資料。

之後可在 Intervals.icu 的 Settings 連接支援的裝置或 app。歷史資料能補多少取決於來源；確認紀錄出現在 Intervals.icu 後，再請教練重新讀取。

設定有卡住？先看連接問題排查。平台入口與方案以官方說明為準：Claude · ChatGPT（2026-09-09 核對）。

讓教練認識你的訓練

連接之前你可能想問

重訓課表會保留哪些內容？

計畫可保留動作、組數、次數與重量，之後可在對話裡請教練讀回。Intervals.icu 收到的是課表名稱；不要把日曆或手錶畫面當成完整重訓內容。

這是一個要安裝的 app 嗎？

不是。它跑在你和 Claude 或 ChatGPT 的對話裡——連接一次之後，你就是跟它講話而已。沒有東西要下載，這裡不用另外註冊帳號，也沒有儀表板要你一直回去看。你的計畫在教練那裡，課表會落到你的 Intervals.icu 日曆。

開始之前需要準備什麼？

只是想試試看的話什麼都不用，直接試玩不需要帳號。要讓它讀你自己的訓練，才需要一個 Intervals.icu 帳號，以及支援連接器的 AI 帳號。第一次建議用 Claude；免費方案可加入一個自訂連接器。ChatGPT 的完整流程目前需要 Business、Enterprise 或 Edu 網頁版及工作區授權。查看設定步驟。

這個要錢嗎？

教練目前免費，沒有付費方案。Intervals.icu 可免費註冊，Claude 也可用免費方案開始；AI 平台本身的使用額度與訂閱費另計。這是獨立開發的早期專案，服務可能調整，沒有不中斷保證。

一定要用特定的手錶嗎？

不用，也可以沒有手錶。教練會使用 Intervals.icu 裡的紀錄，以及你在對話裡回報的訓練。

想跟著手錶練：先確認課表已寫入 Intervals.icu，再用你裝置本身的同步。教練能核對 Intervals.icu 是否收到；手錶有沒有拿到，只有手錶上看得到。

我可以自己架，不用託管版本嗎？

可以。自架跑的是完全一樣的產品，用你自己的 Intervals.icu OAuth 憑證和你自己的儲存空間——這條路是給想自己維運的開發者走的。多數人直接用設定步驟裡的託管網址就好。

為什麼 Intervals.icu 四個權限都要勾？

四項權限分別用來讀取已完成活動、讀取健康與恢復資料、讀寫訓練日曆，以及讀寫運動員設定。設定寫入只用於你已確認的課表交付：缺少門檻配速時補上，已設定的值不會覆寫。日曆課表仍須你確認後才會寫入。漏勾權限時，重新連接並補齊即可。

教練會不會沒經過我同意就寫課表？

不會。每一堂課都會先完整攤給你看，你確認的就是你看到的那一份，確認之後才寫入。

「交付成功」是什麼意思？

交付成功代表 Intervals.icu 已存下這堂課、教練也讀回來核對過。不代表你的手錶已經拿到。

要怎麼撤銷授權或刪掉我的資料？

要停掉存取：到你的 Intervals.icu 設定裡移除這個應用程式，之後的讀寫就停了。Intervals.icu 的授權是給整個應用程式、不是給單一個 AI，所以移除它會一次斷掉你連過的每一個 AI——Claude、ChatGPT，全部。

連資料也想刪掉的話：刪除是 email 申請，不是對話裡做的事——步驟在支援頁。你跟教練說要刪除全部資料，它會把那一頁給你；在你寄信之前，沒有提交，也沒有移除任何東西。先後順序沒差：不管你有沒有撤銷授權，athlete id 都找得到帳號。

不管哪一種，已經寫進 Intervals.icu 日曆的課表都還是你的，要留要刪都可以。更多細節在支援頁。
