跑步＋重訓的自適應 AI 教練

Long Run Hybrid Coach 活在你的 Claude 或 ChatGPT 對話裡。它讀你 Intervals.icu 帳號裡的訓練紀錄，維持一份當前的 28 天跑步與重訓計畫，並在你同意之後，把每一堂課表排進你的日曆。

你的訓練怎麼變，它就跟著調整；你原本用什麼手錶或 app 都可以。

跑步和重訓，共用同一份當前計畫。

生活會變，訓練也該跟著變。少跑掉的那一趟、真的練完的那組重訓、不完整的恢復數據——這些都該影響接下來怎麼練。Long Run Hybrid Coach 會拿計畫去對你實際做了什麼，然後更新你唯一的當前方向。

1

唯一的當前方向

接下來 28 天和這一週會一起變。不會留下一堆過期課表要你自己人工對帳。

2

跑步與重訓一起排

跑步和重訓共用同一週、同一份恢復預算。重訓是計畫的一部分，不是想到才加的東西。

3

照實際發生的事調整

它會先看你實際做了什麼、以及手上拿得到的恢復數據，才動計畫。資料缺了或過期了，就當作「不知道」處理，不會當成零。

重訓寫得很具體。

「背蹲舉 4×5、100 公斤」在你的計畫裡是一堂真的課，不是你留給自己的一行筆記。Intervals.icu 收到的是課表名稱；動作、組數、次數、重量留在對話裡，你隨時可以請它讀回來給你看。

運作方式

你的裝置和 app 把資料送進 Intervals.icu——拿得到多細的資料要看裝置，但教練這一端的運作是一樣的。教練讀那些訓練紀錄，加上你直接告訴它的事。

寫入之前 你會看到完整課表，並親自同意。

日曆權限的意思是教練可以提議一堂課——在你確認你看到的那份完整內容之前，它寫不進任何東西。

寫入之後 教練會回頭跟 Intervals.icu 核對。

交付成功代表 Intervals.icu 已存下這堂課、教練也讀回來核對過。不代表你的手錶已經拿到。

連接之前你可能想問

這是一個要安裝的 app 嗎？

不是。它跑在你和 Claude 或 ChatGPT 的對話裡——連接一次之後，你就是跟它講話而已。沒有東西要下載，這裡不用另外註冊帳號，也沒有儀表板要你一直回去看。你的計畫在教練那裡，課表會落到你的 Intervals.icu 日曆。

開始之前需要準備什麼？

一個 Intervals.icu 帳號，以及 Claude 或 ChatGPT。開始使用頁有要貼的網址和完整四個步驟。還沒有 Intervals.icu 帳號也沒關係，它是免費的——設定流程會帶你到它的登入頁，用 Google 帳號大約 30 秒就能開好。Claude 用免費方案就可以。ChatGPT 目前需要 Business、Enterprise 或 Edu workspace；個人方案請等這個教練在 ChatGPT 目錄上架。

你的 Intervals.icu 帳號是新的或空的嗎？

教練會自動讀 Intervals.icu 裡已經有的資料。你可以在 Intervals.icu 自己的 Settings 裡，連上你原本就在用的裝置或 app——Garmin 或其他手錶、訓練 app 都行——過去的活動會自動補上。或者直接在對話裡把 CSV、Apple Health 匯出檔或 .fit 檔交給教練，請它匯入你的歷史紀錄。（檔案是給教練看的，不會加進 Intervals.icu。）

一定要用特定的手錶嗎？

不用。只要活動紀錄和健康數據最後有進到你的 Intervals.icu 帳號，教練就能用。

我可以自己架，不用託管版本嗎？

可以。自架跑的是完全一樣的產品，用你自己的 Intervals.icu OAuth 憑證和你自己的儲存空間——這條路是給想自己維運的開發者走的。多數人直接用開始使用頁上的託管版本就好。

為什麼 Intervals.icu 四個權限都要勾？

這四個權限讓教練能讀你完成的活動、讀你的健康數據、讀寫你的訓練日曆、讀你的 Run 設定。Run 設定裡放的是你的門檻配速——如果它缺著，教練只能透過你已經確認過的課表把它補回來。每個權限管的是不同一種存取。少勾哪一個，需要它的功能就會用很難查出原因的方式壞掉——要用完整的教練流程，四個都勾。

教練會不會沒經過我同意就寫課表？

不會。每一堂課都會先完整攤給你看，你確認的就是你看到的那一份，確認之後才寫入。

「交付成功」是什麼意思？

交付成功代表 Intervals.icu 已存下這堂課、教練也讀回來核對過。不代表你的手錶已經拿到。

要怎麼撤銷授權或刪掉我的資料？

連存下來的資料也想刪掉？先在對話裡跟教練說——它會在你確認之前，先讓你看到要移除的到底是什麼。然後到你的 Intervals.icu 設定裡移除這個應用程式，停掉之後的讀寫。（如果先撤銷授權，教練會被登出，就沒辦法在對話裡幫你刪資料了。）Intervals.icu 的授權是給整個應用程式、不是給單一個 AI，所以移除它會一次斷掉你連過的每一個 AI——Claude、ChatGPT，全部。已經寫進 Intervals.icu 日曆的課表還是你的，要留要刪都可以。更多細節在支援頁。

為今天而練，也為往後很長的路保住能力。

把教練連上、在 Intervals.icu 授權，然後從你已經練過的東西開始。
