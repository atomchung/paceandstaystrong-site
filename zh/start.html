開始使用 Long Run Hybrid Coach

你需要一個 Intervals.icu 帳號，以及一個支援 remote MCP connector（遠端 MCP 連接器）的 AI client。讓 Coach 讀取你自己帳號裡，原本就有的訓練 evidence。

還沒有 Intervals.icu 帳號？免費——下面的連接流程會帶你到它的登入頁，可以用 Google 帳號在 30 秒內完成註冊。

四步驟完成連接

Remote MCP URL https://mcp.paceandstaystrong.com/mcp
  1. 開啟你 AI client 的連接器設定。

    選擇新增 remote MCP connector 或 remote MCP server 的選項。

    claude.ai 或 Claude Desktop：Settings → Connectors → Add custom connector。

    ChatGPT：完整的 read/write connector 存取，目前依 OpenAI 官方說明，在 Business、Enterprise 與 Edu 的網頁版 workspace 透過 Apps／developer mode 開放 beta；其他人可以先等這個 connector 在 ChatGPT 目錄上架。

  2. 新增 Long Run Hybrid Coach 的 endpoint。

    把上面的網址貼進 remote MCP server 的 URL 欄位，然後繼續。

  3. 授權 Intervals.icu。

    Intervals.icu 開出同意頁時登入，四個權限都勾選，然後核准。少勾一項不會讓連線更安全，而是讓某個功能用難以回溯原因的方式失敗。

    看看這個授權涵蓋哪些範圍，以及要怎麼撤銷。

  4. 回到 AI client，開始對話。

    確認連接器在對話裡可以使用，然後請 Coach 讀你最近的訓練。

試試看：「讀我最近的訓練，幫我排 28 天的跑步＋重訓方向。」

你的 Intervals.icu 帳號是新的還是空的？

Coach 只會讀 Intervals.icu 裡已經有的資料。如果帳號是新的，在請它讀你的訓練之前，有兩種方法可以先把歷史資料補進去：

  • 連接你原本就在用的裝置或 app。在 Intervals.icu 自己的 Settings 裡，連上 Garmin 或你既有的手錶、訓練 app 帳號。過去的活動會自動回填——資料到了之後，再回來請 Coach 重新讀一次你的訓練。
  • 直接把匯出檔上傳給 Coach。在對話裡把 CSV、Apple Health 匯出檔或 .fit 檔直接交給 Coach，請它匯入你的歷史紀錄。

接下來會發生什麼事

Coach 會讀 Intervals.icu 裡可用的 evidence，和你討論目前的方向。如果它提出一筆日曆課表，你會在任何東西寫入前看到完整課表。交付成功，代表 Intervals.icu 已經接受並回傳這筆課表；並不代表手錶或其他裝置已經收到。
