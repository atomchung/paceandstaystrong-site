這些條款規範 Long Run Hybrid Coach 的使用。如果你不同意，請不要使用本產品。

1. 這個產品是什麼

Long Run Hybrid Coach 是一個獨立的訓練規劃工具，寫給同時跑步與重訓的運動員。它會從可取得的訓練紀錄維持一份當前方向。Intervals.icu 是目前的互通樞紐：託管 MCP 透過它把供應商端的紀錄帶進教練循環，也透過它接收你明確同意的結構化課表。自架 gateway 是另一條由維運者自行執行的路徑。

2. 訓練與醫療風險

本產品不是醫療建議。訓練本身帶有風險。當天該不該做這一堂課、需要時該不該停下來、以及是否尋求合格的醫療或教練建議，責任都在你。

3. 同意與交付

沒有你對眼前這份提案的明確確認，任何課表都不會被發佈到 Intervals.icu 日曆。交付狀態只會回報到產品觀察得到的程度：寫入 Intervals.icu 並讀回核對，不代表 Garmin Connect、Apple Watch 或其他下游裝置已經收到這堂課。

4. 連接的帳號

你要為你的 Intervals.icu 帳號、你連接的其他帳號，以及你是否有權使用其中的資料負責。你可以隨時在 Intervals.icu 撤銷 Long Run Hybrid Coach 的存取權。第三方平台的條款，仍然規範你與那些平台之間的關係。

5. 服務可用性

本產品以現況（as-is）提供。它可能改變、故障或停止服務。不對可用時間、交付成功率或功能持續存在做任何保證。

6. 可接受的使用方式

  • 只把本產品用於你自己的訓練，或用於明確授權你的運動員。
  • 不要在未經許可的情況下存取他人的訓練或健康資料。
  • 不要把它的輸出當成醫療、診斷或臨床建議來呈現。
  • 不要以違反所連接平台條款的方式使用它。

你可以在 Intervals.icu 撤銷 Long Run Hybrid Coach 的存取權來停止使用本產品。你也可以依照隱私權政策所述要求刪除資料。本產品的存取權可能隨時被暫停或終止。
