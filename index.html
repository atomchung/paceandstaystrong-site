Train for today. Stay capable for the long run.

Long Run Hybrid Coach is an Intervals-first, device-agnostic coach for athletes who run and lift. It maintains one current 28-day direction from the evidence available to the coaching loop, then changes or delivers workouts only through explicit confirmation.

Get started Read the full guide

Start with an Intervals.icu account—not a specific watch.

Intervals.icu is the current interoperability hub for the product: it brings external activity and wellness evidence into the loop and receives workouts you approve. Garmin is the first downstream device path we have dogfooded, but it is not a prerequisite.

1

Use the hosted MCP

For the shortest path, connect a compatible MCP client to https://mcp.paceandstaystrong.com/mcp, then complete the Intervals.icu authorization flow. You do not need to create an Intervals developer app for the hosted service.

2

Or self-host

Developers who want to operate their own gateway can self-host the same product surface. That path uses their own Intervals OAuth application credentials and their own state root.

3

Ask a normal coaching question

No setup questionnaire is required. Ask what to train this week, review recent work, or define the first 28-day direction. The coach reads existing evidence first and asks only for missing information that changes the decision.

Client availability matters. The hosted endpoint is live, but the ability to add a custom MCP server—and whether that client exposes write actions—depends on the AI product and plan you use. The GitHub Quick Start keeps the current per-client setup and limitations.

One current plan—not a folder of stale plans.

Training changes when life changes. A missed run, a completed lifting session, or incomplete recovery evidence can change what comes next. Long Run Hybrid Coach reconciles trustworthy completed work against the current plan and keeps one current direction rather than reconstructing a second plan from chat history.

1

Run and lift together

Running and strength live in the same weekly plan. Strength is not an afterthought added to a running schedule.

2

Use actual evidence

Completed activities, available wellness signals, and athlete-reported facts inform revisions. Missing or stale evidence remains unknown—not zero.

3

Approve consequential writes

Plan changes and calendar delivery are previewed before their apply step. The product writes only through the confirmation boundary defined for that action.

How Intervals.icu fits into the loop

Device or app → Intervals.icu. A wearable or training app can feed activity and wellness evidence into Intervals.icu. Device-specific richness varies, but the coaching path stays the same.
Intervals.icu → Coach. The coach reads the evidence available there together with athlete-reported facts and the one current PlanState.
Coach → Intervals.icu calendar. When a workout is selected for delivery, you review the exact preview and confirm before it is written.
Intervals.icu → downstream device/app. The product verifies only the Intervals acceptance/read-back it can observe. A successful Intervals write is not proof that the workout reached Garmin, Apple Watch, or another downstream device.

Status

Hosted MCP is live; public distribution is still being prepared. The production endpoint is https://mcp.paceandstaystrong.com/mcp, and real OAuth/coaching/delivery flows have been validated on selected clients. A public app/directory listing is not yet the universal entry, so direct availability still depends on whether your chosen client supports the required MCP connection and actions. The source repository records which entry paths are verified end to end.
